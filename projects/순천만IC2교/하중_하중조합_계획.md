## 3. 하중조합 (도로교설계기준 2005 허용응력설계법, 상부구조에 해당하는 것)

| 조합 | 구성 | 허용응력 증가 |
| :-- | :-- | --: |
| I | D + (L+I) + CF | 100 % |
| II | D + W | 125 % |
| III | D + (L+I) + CF + 0.3W + WL + LF | 125 % |
| IV | D + (L+I) + CF + T (+S) | 125 % |
| V | D + W + T (+S) | 140 % |
| VI | D + (L+I) + CF + 0.3W + WL + LF + T (+S) | 140 % |

D = D1 + D2. 토압(E)·부력(B)·유수압(SF)은 상부구조에 해당 없음. 정밀안전진단 안전성평가에서는 **조합 I이 지배**하는 것이 보통이고, 나머지는 응력 검토 시 허용응력 증가와 함께 봅니다. `(확인: 검토할 조합 범위)`

## 4. 모델 수정 사항 (하중과 별개로 바로 반영)

1. **좌표축 수정** — 받침 배치도 좌표는 X=북, Y=동인데 X를 동으로 놓아 평면이 거울상이었음. 수정 후 A1 좌측(원점), P5 우측(+X), 곡선 방향·G1/G2 위치가 도면과 일치.
2. **지점 가로보 누락** — 허용오차 문제로 P1~P5 지점 가로보가 빠져 있었음(5 m 격자 위치만 생성). 수정.
3. **받침 국부축** — 일방향 받침은 접선방향 이동 허용, 양방향은 양방향 허용, 고정단 P3. 지금은 전역 Y 구속이라 온도·제동하중이 들어가면 곡선교에서 과대 구속됨. 배치도의 받침 좌표로 주형별 받침 종류를 정해 반영.
4. **강재 할증 재산정** — 가로보 길이를 절점 간 실제 길이로 두어 1.43 → 약 1.40.

## 5. 결과 처리 순서 (하중조합 확정 후)

모델 A·B·C 결과 → 조합별 부재력(포락) → 단면응력(합성전·후 단면별 응력 합산, 건조수축 포함) → 허용응력(SM490 190 MPa, 증가계수) 대비 → 표·삽도 → 보고서.
