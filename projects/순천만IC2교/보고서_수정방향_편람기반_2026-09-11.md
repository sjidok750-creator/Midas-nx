## 1. 결론(방침)

1. **하부구조 절은 편람 예제의 [단계] 순서를 그대로 절 구조로 쓴다.** 교대 = 509.1 단계 1~9, 교각 = 509.2 단계 1~8. 단계 번호를 보고서 소제목에 남긴다(예: "5.x.3 [단계 3] 하중산정"). 삽도·표는 편람 예제와 같은 자리에 같은 형식으로 두되, 그림은 우리 도면 판독 결과(DXF 크롭)·NX 캡처·자체 작도(matplotlib)로 채운다. 편람 그림을 복사하지 않는다.
2. **설계법은 편람과 같게 "안정검토 = 허용응력설계법(안전율), 단면검토 = 강도설계법(도로교설계기준 2010 식 ①~⑨)"로 통일한다.** 어제 교대에 적용한 한계상태설계법(KDS γp·저항계수)은 본문에서 빼고 "참고: 한계상태설계법 검토" 부록 표 하나로만 남긴다. 이유: 상부(허용응력법)·교각(강도설계법 ①~⑨)·편람 예제가 모두 2010 체계라서 교대만 KDS면 보고서 안에서 기준이 섞인다. 단, 2010 기준이 수치를 주지 않는 항목(교대 kh, 흉벽 윤하중, 응답수정계수 세부)은 최신 기준(KDS 24 17 11:2022, 2020 도로설계요령)을 인용한다.
3. **진단이므로 편람의 "가정 → 검토 → 단면조정" 루프를 "도면값 입력 → 검토 → 안전율/강도비 → 판정"으로 바꾼다.** 배근 결정·철근조립도 단계는 "도면 배근 현황 → 강도비(φMn/Mu, φVn/Vu)"로 대체하고, 미달 항목은 단면 조정이 아니라 "보수·보강 필요"로 결론짓는다.
4. **상부구조는 편람 506.4 단계 1~4·11·12를 절 구조로 쓰고, 5~10·13(이음·보강재·가로보·세로보·다이아프램·전단연결재·부대시설)은 진단 범위에서 제외하되 제외 사유를 한 줄 명시한다.** 현재 v3의 상부 절(단면제원·유효폭·하중·모델링·부재력·응력검토·합성응력·항복검토·처짐·내하력)은 이미 편람 4-1~4-4와 같은 뼈대라서 순서 정리와 표 형식 통일만 하면 된다.
5. 결론 절은 편람의 "OK/N.G" 나열이 아니라 **항목별 안전율·응력비 표 → 최소값 → 등급 → 보수·보강 소견** 순으로 쓴다.

## 5. 진단이라서 편람과 달라지는 점(보고서에 명시할 원칙)

1. 단면·배근은 준공도면 값이며 조정하지 않는다. 배근도가 없는 부재는 소요 철근량만 제시하고 "배근 확인 필요"로 남긴다.
2. 판정은 안전율(허용/작용), 응력비(작용/허용), 강도비(소요/설계강도)로 통일하고, 각 절 끝에 표 1개로 모은다.
3. 지반·말뚝 지지력처럼 자료가 없어 산정 불가한 항목은 값을 만들지 않고 "산정 불가(자료: ○○ 필요)"로 쓴다.
4. 지점침하·크리프·건조수축은 완공 후 장기 진행이 끝났다고 보되, 응력 조합에는 기준대로 포함한다(안전측).
5. 결론: 최소 안전율·응력비로 부재별 등급 → 보수·보강 소견. 설계 예의 "단면 변경" 문구는 쓰지 않는다.

## 6. 작업 순서(코드 → 보고서)

1. abutment2.py 개정: 2010 체계(안전율·식 ①~⑨)로 되돌리고 LSD는 옵션(--code kds) 부록용. 추가: 연단거리·지지길이, 받침 용량, 하중집계표(편람 형식), 전도·활동 안전율, 말뚝 반력표(열별·고정/힌지), 본체 휨응력(Chang), 흉벽 윤하중, 앞굽·뒷굽 단면력. 편람 2008 예제 수치로 **회귀검증**(P_a 205.12, K_a 0.271/0.251, K_ae 0.363, 말뚝 R4 686.97 등).
2. pier_model.py 확장: 제상수 표, S·N, 조합표 출력, 하중별·조합별 단면력 표, 브래킷/깊은보 판정, 세장비·δs, P-M 상관도 그림, 강체판정, 말뚝 휨응력, 받침 용량. 편람 T형 예제 수치로 회귀검증(브래킷 av/d 0.647, Q 0.085·δs 1.093, Kv 304,151.770 등).
3. stress3.py: 표 3.9.4 증가율, 표 3.4.3 국부좌굴, 항복검토(어제 대조표 A·B·D).
4. 삽도: dxf_crop으로 교대·교각 도면 부분 크롭(정면·측면·평면·받침부), NX 캡처(변단면 렌더·하중 재하도·모멘트도), matplotlib(하중 블록도, 토압 분포, 말뚝 배치·반력, P-M 상관도).
5. build_ch5_v4.py: v3 문단을 편람 단계 순서로 재배치·신설(원본 XML 복제 원칙 유지), 표 헤더 통일, 결론 표.

## 7. 대표님 결정이 필요한 항목

1. 설계법 통일: 본문 2010 체계(안정 허용응력·단면 강도설계), KDS는 부록 — 이대로 갈지.
2. 활하중: DB-24 유지(준공 기준) 여부. 흉벽 윤하중은 DB-24 후륜 96 kN으로 환산 예정.
3. 배근도(교대·교각·기초)와 지반조사서·말뚝 시공기록: 있으면 주시면 강도비·지지력까지 산정. 없으면 "확인 필요"로 둠.
4. 제외 범위: 접속슬래브·날개벽·피로·이음·보강재·다이아프램 — 제외 방침에 동의하는지(날개벽은 도면이 있어 넣을 수도 있음).
5. 지진: 정적등가(단일모드) 유지 vs NX 응답스펙트럼 해석 추가.
