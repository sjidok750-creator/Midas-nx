## 4. 확인 필요 (모델 생성 전 답 필요)

1. **A1/P5 방향** — 받침 배치도의 라벨 위치로 A1 = X 155599.05 / P5 = X 155445.28 로 읽었음. 9/9 추출은 반대였음. 종평면도 경간(49.840 … 49.890) 순서와 이번 판독이 일치하지만 도면에서 직접 확인 필요
2. **고정단 위치** — 집계표는 P3 고정단 1개. 받침좌표표의 '700톤 고정단' 좌표(X 155503.4)도 P3에 해당 → 일치. 다만 배치도 첫 집계표에는 고정단 0으로 나오는 행이 있어 확인 필요
3. **경간장** — 받침좌표 역산 49.84/50.00/70.00/50.00/49.88 vs 종평면도 49.840/50.000/70.000/50.000/49.890. 단면요약도의 49.290/49.340은 거더 단부 500 제외 분절 길이
4. **2차 고정하중** — 포장 두께(도면 'T=50mm' 표기 확인), 방호벽 단면(450/620) 중량 — 구조계산서 값으로 확정 필요
5. **종리브·수평보강재** — 단면 특성에 종리브(U-rib 등) 포함 여부 — 구조계산서 단면표와 대조
6. **모멘트도 하중조합** — 단면 요약도의 Max 값이 어느 조합(합성전/후, D+L+I)인지 미확인
