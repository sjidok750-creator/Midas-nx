## 1. 일치 항목 — 우리 모델이 도면 판독을 제대로 했음을 확인

| 항목 | 구조계산서 | 우리 모델 |
|---|---|---|
| 교량형식 | 합성형 STEEL BOX GIRDER **2련** | 강박스 **2주형** (G1/G2) |
| 교량등급 | 1등급, DB-24 / DL-24 | 동일 |
| 사각 | 90.0° | 90° |
| 박스 높이 H | **2.300 m** | **2.300 m** |
| 바닥판 두께 | hmin=24.2cm → **30cm 사용** | **300 mm** |
| 바닥판 fck | 270 kgf/cm² = **27 MPa** | **27 MPa** |
| 강재 | SM490 / SM400 | SM490B / SM400B |

**주형 간격 검산 — 완전 일치**

계산서의 유효폭 산정 파라미터로 횡단을 복원하면:
```
2 × X2(캔틸 1.200) + 2 × 박스폭(2.000) + X1(복부사이 2.270) = 8.670 m  ✓ 전폭 일치
주형 중심간격 = X1 + 박스폭 = 2.270 + 2.000 = 4.270 m
```
우리가 받침간격에서 얻은 **4.270 m와 정확히 동일**합니다.

> 주의: 계산서의 `X1=2.270`은 *두 주형의 복부 사이 순간격*이고,
> 우리 모델의 `web_spacing=2.258`은 *한 박스 내부 복부 중심간격*입니다.
> 서로 다른 값을 지칭하므로 불일치가 아닙니다.

## 2. 차이 항목

### (1) 경간장 — 성격이 다름 ★

| | 값 | 합계 |
|---|---|---|
| 구조계산서 | 50 + 50 + 70 + 50 + 50 | **270.000 m** |
| 우리 모델 | 49.876 + 49.996 + 70.000 + 50.000 + 49.840 | **269.712 m** |

계산서는 **설계 원형값**, 우리는 **준공도면 받침 실좌표 역산값**입니다.
종평면도(49.840 / 50.000 / 70.000 / 50.000 / 49.890)와 50mm 이내로 교차검증됨.

**정밀안전진단은 현 상태 평가이므로 준공 실측값이 타당**하나,
계산서와 수치 대조 시 0.288m 차이를 인지해야 합니다.

### (2) 바닥판 유효폭 — 계산서가 더 정밀 ★★

계산서는 **경간·지점별로 9개 값**을 개별 산정했습니다.

| 위치 | 계산서 유효폭 | 우리 모델 | 차이 |
|---|---|---|---|
| 제1지간 중앙부 | 4.005 m | 4.335 | +8.2% |
| 제1중간 지점부 | **3.967 m** | 4.335 | **+9.3%** |
| 제2지간 중앙부 | 4.335 m | 4.335 | 0% |
| 제2중간 지점부 | 4.066 m | 4.335 | +6.6% |
| 제3지간 중앙부 | 4.335 m | 4.335 | 0% |
| 제3중간 지점부 | 4.056 m | 4.335 | +6.9% |
| 제4지간 중앙부 | 4.335 m | 4.335 | 0% |
| 제4중간 지점부 | **3.967 m** | 4.335 | **+9.3%** |
| 제5지간 중앙부 | 4.335 m | 4.335 | 0% |

**우리 모델은 전 구간 4.335m 일괄 적용 → 지점부에서 최대 9.3% 과대평가.**

계산서 산정식 (도로교설계기준):
```
지간 중앙부 : l = 0.8 × L
중간 지점부 : l = 0.2 × (L_i + L_i+1)
b/l 에 따라 λ 산정 → B = 플랜지유효폭 + λ1 + λ2 + h
```

유효폭 과대 → 합성단면 Iy 과대 → **지점부 부모멘트·응력 과소평가** 방향.
정밀안전진단에서는 안전측이 아니므로 보정이 바람직합니다.

## 3. 조치 제안

**즉시 반영 가능**
- 유효폭을 경간·지점별 9개 값으로 세분 → 지점부 정밀도 확보

**대조 시 유의**
- 경간장 270.000(설계) vs 269.712(준공) 차이

**추가 확인 필요**
- 계산서의 2차 고정하중(포장·방호벽) 값 — 우리 모델 미입력 상태
- 계산서 모델의 절점·요소 구성 (해당 페이지 미확인)

## 4. 결론

**우리 모델의 도면 판독은 정확합니다.** 형식·박스높이·바닥판·재료·주형간격이
독립적으로 산정했음에도 계산서와 일치했습니다.

**보정이 필요한 것은 유효폭 하나**입니다. 나머지 차이는 성격 차이(준공 실측 vs 설계 원형)
이거나 우리 모델이 더 정밀한 부분입니다.
