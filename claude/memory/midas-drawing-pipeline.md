도면 판독은 **DXF 문자 추출(좌표 포함)**을 주 통로로, 이미지는 형상 확인용으로만 쓴다. 문자 추출은 도면 한 장에 토큰 수백이고, 이미지 한 장은 약 1,600토큰인데 한글 글꼴·해상도 문제로 숫자 판독이 불안하다.

## 도구 (`D:\Midas\tools\`)

- `dwg2dxf.py <출력폴더> <dwg|폴더>... [--glob 패턴]` — ODA File Converter 27.1 CLI. 인자 없이 실행하면 GUI가 떠서 멈추니 주의. bash에서 `/F` 같은 옵션은 MSYS가 경로로 바꾸므로 taskkill은 PowerShell `Stop-Process`로.
- `dxf_extract.py <dxf|폴더> <출력폴더>` — TEXT/MTEXT/ATTRIB(블록 내부 포함)와 DIMENSION → JSON(`texts`, `dims`, `rows`=y로 묶은 표 복원, `layers`, `bbox`). 이 도면들은 치수가 폭발된 상태라 `dims`가 0이고 숫자는 전부 문자로 잡힌다.
- `dxf_render.py`, `dxf_crop.py <dxf> <png> --find "정규식" --pick N --margin M` — matplotlib 렌더(맑은 고딕 지정). 전체 시트는 판독 불가하니 항상 `--find`로 기준 문자를 잡아 부분 확대.
- `spec_build.py` — 순천만IC2교 전용 제원서 생성기. 지점 좌표·판두께 분할 자동, 판독 값은 출처 도면번호와 함께 `MANUAL`, 미확정은 `CHECK`.

## 실측된 함정 (2026-09-10, 순천만IC2교 준공도면)

- **표의 두께 행이 길이 행과 다른 y에 있다.** 하판 지점부 5 m×4 구간이 한 줄 아래에 따로 적혀 있어 9/9 추출은 20 m가 비었다(합 249.63 vs 269.63). 길이 합계 = 거더 길이 검산을 반드시 한다. 두께 매칭은 x만이 아니라 x·y 유클리드 거리로.
- **받침 배치도의 좌표표가 둘**(A1·P5는 두 표에 다른 값, 약 0.1 m 차이). 종평면도 경간(49.840/…/49.890)과 맞는 쪽을 택하고 대안을 기록했다.
- **라벨 위치로 A1/P5를 정하면 반대로 읽힐 수 있다.** 9/9는 A1↔P5가 뒤집혀 있었다. 종평면도 경간 순서로 교차검증.
- 단면 요약도에는 **설계 휨모멘트도(Max ± ton·m)** 가 들어 있어 해석 정답지로 쓸 수 있다(어느 조합인지는 미확인).
- 이 교량: 강박스 2련, 박스 폭 2.000(복부 수직)·높이 2.100/2.300, 거더 간격 4.270, 폭원 8.670, 슬래브 300, 다이아프램 5 m, 복부 12 mm 전장(요약도), 고정단 P3.

**How to apply:** 새 교량은 ① `dwg2dxf` → ② `dxf_extract` → ③ `rows`에서 키워드 grep → ④ 형상만 `dxf_crop` → ⑤ `spec_build` 형태의 제원서 + 확인표 → 대표님 확인 후 모델. 산출물은 `D:\Midas\projects\<교량>\`. 관련: [[midas-open-api]], [[midas-mct-syntax]]

- **하부구조(교대) 판독 함정(2026-09-10):** 단면 확대 그림을 눈으로 읽으면 앞굽/뒷굽이 뒤집힌다. 반드시 `toolsbut_geom.py`처럼 문자 좌표로 판정: 3연속 치수 행(앞굽·벽체·뒷굽) + 흉벽 소치수(300/500…)가 있는 쪽 = 뒷채움, 'SHOE' 문자 쪽 = 교량, '1:1' 문자 = 헌치면, 기초평면 원 기호 군집 = 말뚝 본수. 상충하면 ★플래그로 사람 확인. 대표님 원칙: 도면을 주면 사람 개입 없이 계산까지 가야 하므로 판독 근거를 JSON에 남긴다.
