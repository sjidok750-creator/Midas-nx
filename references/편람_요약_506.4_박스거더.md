## 0. 4.1 설계일반사항 (요점)

- 적용 지간 40~80 m. 80 m 이상이면 강바닥판이 많다. 설계방법은 플레이트거더교에 준하되, 다실박스는 전단류 이론으로 검토.
- 일반제원: 거더높이–지간장 <그림 506.4.1>, 지간장–강재중량 <그림 506.4.2>, 단면치수 실적 <그림 506.4.3>(단일/병렬/곡선). 후판(SM520·SM570·TMC, t = 40~100 mm) 적용 시 거더높이·강중 적정성을 별도 검토.
- 주거더 플랜지 설계 조건(4.1.3): ① 휨응력 ≤ [도‧설 3.3.2.1] <표 3.3.1>·<표 3.3.4> 허용응력 ② 단면2차모멘트 산정 시 전단지연 → [도‧설 3.8.3.4 플랜지의 유효폭] ③ 박스는 횡강성이 크므로 **휨허용응력 = 인장허용응력** ④ 압축플랜지 판두께 [도‧설 3.4.2] (보강재 충분하면 고정단 거리 b = 복부판 중심간격) ⑥ 인장플랜지 두께 [도‧설 3.8.3.2] ⑧ 하부플랜지 돌출길이: 동바리 필요시 용접각장 끝에서 80 mm 이상, 불필요시 15~30 mm <그림 506.4.4>.
- 다이아프램(4.1.4): 효과 = 단면형상 유지·강성 증대·집중하중 전달. 형식 = 충복판/라멘/수직브레이싱 <그림 506.4.10>. 개구율 (506.4.1) (원문 수식 깨짐), 간격 (506.4.2) (원문 수식 깨짐; <그림 506.4.13> 다이아프램 간격–등가지간장 관계), 강성 K ≥ … (506.4.3) (원문 수식 깨짐), I_DW (506.4.4)~(506.4.6) (원문 수식 깨짐), 충복판 강성 (506.4.7), 라멘 (506.4.8)·보정 (506.4.9) <그림 506.4.17>, 수직브레이싱 X형 (506.4.10)·V형 (506.4.11), 응력검토 (506.4.12)~(506.4.15), 지점부 지압 (506.4.16)·연직응력 (506.4.17) — 모두 (원문 수식 깨짐). 지점부 다이아프램 유효폭 B_e = 소울플레이트 폭 B + 하부플랜지 판두께 t_f×2 <그림 506.4.22>, 연직응력은 하단 최대 삼각형 분포 <그림 506.4.23>, 수평방향은 [도‧설 3.8.2.5] 식(3.8.6) 2축응력 검토.
- 받침부(4.1.5): 받침 수 최소화가 유리. 병렬박스 1박스 1받침은 부반력 경감·시공오차 결함 최소화.

### 4.3 설계단계별 고려사항에서 제시한 근거 조항·판정 기준(요약)

- **[단계 1]** 교량 등급 [도‧설 1.3]; 강박스 적용 지간 40~80 m, 사각 30° 미만이 적합(45°까지 가능). 재료 [도‧설 2.3.1, 2.3.2, 3.2.5]; 주부재 SM490·부부재 SM400이 보편(주부재 = 플랜지·복부판·종리브·수평보강재·지점보강재·교좌장치 가설위치 가로보·1거더 1받침 지점부 가로보·지점부 수직보강재 및 격벽·이음판·소울플레이트). 허용응력 [도‧설 2.2.2.3, 2.2.2.4, 3.3, 3.13.3]; 물리상수 [도‧설 2.3.3]. 하중 [도‧설 2.1]; 고정 [2.1.2]·활 [2.1.3]·충격 [2.1.4]·크리프/건조수축 [2.1.7]·온도 [2.1.12]·지점침하 [2.1.15]. 프로그램: 3차원 격자모델 + 활하중 편심재하 가능한 공인 프로그램. 시공: 합성/비합성, 가설단계별 구조계 변화 시 단계별 해석.
- **[단계 2]** 2차로→주거더 2개, 3차로→3개. 운반 제한: 거더 폭·높이 3.0 m 이내, 제작길이 10.0 m 내외, 제작중량 20톤 이내. 지간–형고 경험식 (506.4.18) (원문 수식 깨짐; 본문 "지간 50 m → 주거더 높이 2.5 m"). 형상: 제형/상자형, 개구제형은 비추천; 55 m 이상 장지간·미관 요구 시 변단면; 곡률반경 작으면 1받침. 표준단면: [도‧설 3.8.3 플랜지], [3.8.4 복부판]; 플랜지·복부 최소두께 10 mm, 플랜지 최대 38 mm 권장(최근 100 mm 이내 사례). 보강재 [3.4.2.4, 3.8.5, 3.8.6]; 수평보강재 1단 원칙·2단 이내; 종리브 최소간격 330 mm; 수직보강재·횡방향 보강재 간격 2.5 m, 격벽 5.0 m. 고강도 후판 시 플랜지 보강재 5개(압축)/2개(인장) → 3개/1개 로 감소 가능(한국도로공사 2007). 유효폭: 강플랜지 [3.8.3.4], 바닥판 [3.9.2.4].
- **[단계 3]** 바닥판 [도‧설 3.6.1.1~3], 최소두께 [3.6.1.5]; 지지간격 3.0 m 이하(변단면 3.3 m). 경험적 설계법 [3.6.3]. 하중 [2.1.2, 2.1.3], 설계휨모멘트 [3.6.1.4], 충격 [2.1.4], 충돌·풍 [2.4.3.3, 2.1.11], 조합 [2.2.3.2]. 휨균열 [4.4.9.4], 철근 [3.6.1.6], 단부 보강 [3.6.1.11], 인장 바닥판 [3.9.2.3].
- **[단계 4]** 고정하중 합성전/합성후 구분 [2.1.2]. 격자 3차원 모델링 원칙(주거더·가로보·세로보); 합성거더면 주거더·가로보에 바닥판 강성 고려, 세로보는 미고려. 바닥판 자중은 2차원 모델 반력 → 3차원 재하. 활하중은 가까운 거더에 편심재하(바닥판 횡분배 미고려 원칙, 세로보에 활하중 미재하). 응력 [3.8.2.1, 3.9.3.1] — 국부좌굴 고려한 감소 허용응력; 2차 부정정력 [3.9.2.6~8]; 항복검토 [3.9.3.2] (고정 1.3배 + 활(충격 포함) 2.15배 + …); 전단·비틀림 [3.8.2.2, 3.8.2.3]; 합성응력 [3.8.2.4].

## 2. 4.4 박스거더교 설계 예 — [단계 1] ~ [단계 13]

### [단계 1] 설계조건 (4.4.1)

**(1) [단계 1-1] 교량의 제원**
- 형식: 강박스거더교 / 등급: 1등교 / 연장: 55.0 + 2@60.0 + 55.0 = 230.0 m / 폭원: 12.60 m

**(2) [단계 1-2] 사용재료**
- 주부재 SM490(상‧하 플랜지, 복부판, 종방향 보강재, 수평보강재, 지점보강재, 주부재 이음판, 소울플레이트, 받침부 다이아프램)
- 부부재 SM400(가로보, 횡방향 보강재, 일반부 다이아프램, 수직보강재, 세로보)
- 콘크리트: fck = 27 MPa, Ec = 27,804 MPa

**(3) [단계 1-3] 설계 하중**
- 고정하중: 바닥판 자중, 거더 자중, 포장, 난간, 기타
- 활하중: 설계차로수 N = 3차로(연석간 교폭 Wc = 11.70 m); DB-24 및 DL-24
  - DL-24: 차로당 점유폭 W = Wc/N = 11.70/3 = 3.900 m(＞3.6 m); 등분포하중 Wℓ = 12.7 kN/m; 모멘트용 집중하중 Pm = 108 kN; 전단력용 집중하중 Ps = 156 kN
  - DB-24: 전륜 24 kN, 후륜 96 kN
- 충격계수 [도‧설 2.1.4]: I = 15 / (40 + L) ≤ 0.3, L: 지간(m)
- 온도차: ΔT = ± 10 ˚C, 선팽창계수 α = 0.000012
- 탄성계수비: n = 8 표준
- 건조수축: εs = 0.00027, φ₂ = 2φ₁ = 4.0, n₂ = n × (1 + φ₂/2) = 24
- 크리프: φ₁ = 2.0, n₁ = n × (1 + φ₁/2) = 16
- 지점침하: 합성후 단면에 대하여 각 지점 위치별 10 mm의 부등침하를 조합하여 적용

**(4) [단계 1-4] 사용 프로그램**: 3차원 해석 + 2차원 평면 프레임 해석 가능 프로그램. 가로보를 모델링에 포함(횡분배 고려). 활하중은 편심 이동하중 재하 → 하중조합으로 최불리 단면력.

## 3. 설계 예와 진단(기존 교량 안전성 평가)의 대응

편람 506.4는 신설 설계 절차만 다루며, 진단(정밀안전진단 안전성평가)에 관한 기술은 없다. 아래 "진단에서의 대응" 열은 편람 밖의 일반 관행을 정리한 것이므로 실제 과업의 지침(시설물 안전 및 유지관리 실시 세부지침 등)과 대조가 필요하다.

| 단계 | 설계 예(편람 4.4) | 진단에서의 대응 |
|---|---|---|
| 1 설계조건 | 신설 제원·재료·하중(DB-24/DL-24, 1등교)·프로그램·시공법을 설계자가 정함 | 준공도면·시방서·과거 보고서에서 제원 취득. 재료강도는 도면값 + 현장시험(반발경도·코어·강재 두께측정)으로 확인. 하중은 준공 당시 설계기준(예: DB-24) 또는 현행 기준 중 과업 지시에 따름. 실측 단면손실·부식을 단면정수에 반영 |
| 2 단면가정 | 16개 표준단면 가정 → 검토 후 수정 반복 | 단면은 이미 확정. 도면 기반 단면정수 산정, 손상(부식·두께감소)이 있으면 유효단면으로 감소 |
| 3 바닥판 | 캔틸레버 강도설계(Mu = 81.593 kNm, As 검토), 중앙부 경험적설계, 단부 보강, 인장바닥판 2% 철근 | 바닥판은 통상 상태평가(균열·백태·열화) 위주. 안전성평가 시 도면 배근으로 휨 내하력·응력비 산정; 경험적설계 바닥판은 별도 응력검토 대상이 아닌 경우가 많음 |
| 4-1 하중산정 | 합성전/합성후 고정, 활하중(차로폭·충격), 지점침하 10 mm, 크리프·건조수축·온도차 2차 부정정력(k값) | 동일 항목이나 지점침하·건조수축·크리프는 완공 후 장기간 경과로 대부분 진행 완료 → 통상 고정+활(+충격)+온도 중심. 실측 처짐·응력 있으면 응답보정계수 산출에 활용 |
| 4-2 모델링 | 3차원 격자(주거더 2 + 가로보 + 세로보), 1차 고정=비합성·2차=합성 강성, 활하중 편심 이동하중, 해석은 전단면·응력은 유효폭 | 같은 격자모델(MIDAS 등) 재구축. 합성/비합성 여부는 준공도면·스터드 유무로 결정. 내하력 산정용 활하중은 재하시험 차량 또는 설계활하중 영향선 |
| 4-3 단면력 | 단면 5(정)·단면 10(부) 거더별 표, 반력 집계 | 동일 표 형식. 모든 단면변화점 또는 최대 응력 단면에서 산출 |
| 4-4 응력검토 | 가~바 6케이스 조합, 허용응력 190 (온도 포함 218.5), 국부좌굴 fca 식, 합성응력 ≤ 1.2, 항복검토(1.3D + 2.15L) | **응력비 = 작용응력/허용응력** (허용응력법) 으로 표시. 기본내하율 RF = (fa − fd)/(fl(1+i)) 를 휨·전단별로 산정, 공용내하력 P = Ks × RF × Pr (Ks = 응답보정계수, 재하시험 시). 항복검토(1.3D+2.15L)는 진단에서는 보통 생략 |
| 5 이음 | SP-6 볼트·이음판·용접 치수 검토 | 볼트 이완·부식은 상태평가 항목; 안전성평가에서 이음부 응력비 검토는 지시가 있을 때만 |
| 6 보강재 | 종리브·횡리브·수직/수평보강재·지점보강재·잭업보강재 필요강성 vs 사용강성 | 통상 생략. 좌굴·변형 등 손상이 관측되면 해당 부재만 재검토 |
